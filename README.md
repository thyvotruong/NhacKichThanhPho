# 🎭 NHẠC KỊCH THÀNH PHỐ WEBSITE

## 🚀 HƯỚNG DẪN KHỞI CHẠY 

### Bước 1: Khởi động Backend API Server (Node.js & MongoDB)
```powershell
cd backend
npm start
```

### Bước 2: Khởi động Frontend Single Page Application (Angular)
```powershell
cd frontend
ng serve -o
```

### Bước 3: 
Mở trình duyệt web và truy cập địa chỉ:
- 🌐 **Trang client:** `http://localhost:4200`
- 🎭 **Trang admin:** `http://localhost:4200/internal`
